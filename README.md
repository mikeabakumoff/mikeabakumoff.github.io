# mikeabakumoff.github.io

Source of my personal site, served at
**[mikeabakumoff.github.io](https://mikeabakumoff.github.io/)**.

A single static page: services, selected cases, pricing and contacts. Plain HTML
and CSS, no JavaScript, no build step — GitHub Pages serves `index.html` from
`main` as-is.

Edit `index.html`, push to `main`, and the site updates.
